# This repo's GitHub issues

GitHub issues are the to-do list. Every repo-specific value (repo, Project number, milestones,
labels, board fields) lives in `config.mjs` in this folder; the scripts read it from there.
The scripts themselves come from claude-workflow (`.claude/workflow.lock.json` says which version).
